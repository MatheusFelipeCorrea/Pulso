# 7. Projeto da Solução

Telas construídas no Pulso (Web React + app Flutter na mesma API). As capturas de protótipo ficam em [`docs/prototipos/`](prototipos/). Os exports da **Sprint 5** (conta/apagar, dashboard redesenhado, grupos/chat, dívidas, divisão, importação e landing Free/Premium) entram nessa pasta quando o time publicar os PNGs — até lá, a descrição abaixo documenta o que já roda no código.

## 7.1 Autenticação e conta

| Tela | Descrição |
| --- | --- |
| Landing (só web) | Homepage pública com módulos, CTAs Entrar/Cadastrar e planos **Free R$ 0** / **Premium R$ 50/mês** (sem checkout — demonstração freemium). |
| Login / Cadastro | E-mail ou usuário + senha, Google OAuth, lembrar-me, links de termos e privacidade. |
| Recuperação / verificação | Fluxos de e-mail (esqueci senha, criar nova senha, confirmar e-mail). |
| Perfil | Edição de dados do usuário (nome, avatar) alinhada web × Flutter. |
| Configurações | Senha (contas locais), tema claro/escuro, modo de uso e **Apagar minha conta** com modal crítico (digitar `APAGAR`) → `DELETE /api/auth/me`. |

Protótipos já versionados (auth clássico): `Login.png`, `Cadastro.png`, `Recuperar Senha.png`, `Criar Nova Senha.png`, e-mails de confirmação/alteração.

## 7.6 Insights Inteligentes e Chatbot (Sprint 6)

| Tela | Descrição |
| --- | --- |
| Insights (`/insights`) | Resumo mensal em linguagem natural (Gemini), variação por categoria, score 0–100 + histórico, projeções 3/6/12 meses, alertas preditivos, sugestões acionáveis e educação financeira — web + Flutter. Cache em `InsightSnapshot`; cota de regeneração. |
| Chatbot (`/chatbot`) | Perguntas em linguagem natural sobre saldos, metas e categorias; histórico de conversas (`ConversaChat` / `MensagemChat`); propostas de lançamento confirmáveis na UI. |

Rotas API: `GET/POST /api/insights`, `POST /api/insights/regenerar`, `GET /api/insights/historico-score`; `GET/POST /api/chatbot/*`. Env: mesma família Gemini do PDF (`GEMINI_API_KEY_*`).

## 7.7 Observação

Flutter **não** inclui landing; a sessão mobile começa no login. Web e mobile compartilham o contrato `/api` e o canal Socket.IO dos grupos. Demo local: `node scripts/reseed-tester.js` em `Codigo/Pulso/api` (`tester@mail.com` / `Pulso@123`) popula todos os módulos acima.
