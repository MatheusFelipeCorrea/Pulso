# 5. Wireframes

> Wireframes são protótipos das telas da aplicação usados em design de interface para sugerir a
> estrutura de um site web e seu relacionamentos entre suas
> páginas. Um wireframe web é uma ilustração semelhante ao
> layout de elementos fundamentais na interface.

Exports em [`docs/prototipos/`](prototipos/). Cada tela do recorte atual tem **modo claro** e **modo escuro**.

**Navegação (recorte atual):** auth → transações, metas, viagens e moedas. Exports em [`docs/prototipos/`](prototipos/), cada tela em **modo claro** e **modo escuro**.
